# vibe-reader

vibe-reader представляет собой десктопную читалку для Linux. Она показывает
EPUB, FB2, Markdown, TXT, HTML и PDF с аккуратной типографикой, а у каждой книги
может быть своя атмосфера: палитра, шрифты, фон и спокойные эффекты частиц.

Встроенного ИИ в приложении нет. Вместо него консольная утилита `vibe-reader` и
поставляемые Skills дают внешним агентам вроде Claude Code или Codex читать
библиотеку, обсуждать с вами главу, вести заметки и настраивать атмосферу.
