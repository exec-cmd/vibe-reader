# vibe-reader

vibe-reader is a desktop book reader for Linux. It renders EPUB, FB2, Markdown,
TXT, HTML and PDF with careful typography, and lets each book carry its own
atmosphere: palette, fonts, background and quiet particle effects.

There is no AI inside the app. Instead, the `vibe-reader` command-line tool and
the bundled Skills let external agents such as Claude Code or Codex read your
library, discuss a chapter with you, keep notes and set the atmosphere.
