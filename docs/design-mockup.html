        Архитектура vibe-reader

        Ядро на Rust. GUI на Tauri, CLI использует то же ядро.

        Режимы CLI

        • offline: напрямую с библиотекой
        • live: через локальный IPC, если GUI запущен
        $ vibe-reader open architecture.md
$ vibe-reader context --json
        Профиль пресета «» (TOML)

        Агент выбирает пресет по имени и не пишет CSS. Автор пресета может положить рядом CSS-файл.

        
  
        

  
        
    
        Что меняет пресет
        Цвета и шрифты, фоновый слой (лампа и полки, сетка, жалюзи, туман, облака, хребты), частицы, иллюстрацию главы и оформление заголовка.
        
    
        Режимы
        Дождь и гроза существуют только в тёмном варианте. Пресет сам объявляет, какие режимы поддерживает.
        
    
        Частицы
        Рисуются одним лёгким canvas, останавливаются при смене окна на лайт-режим, при скрытой вкладке и при prefers-reduced-motion. Вспышка грозы редкая и слабая.
        
    
        Библиотека
        Группируется по вашим полкам или по авторам, статусов «читаю» и «закончил» в виде групп нет. Мини-полка показывает недавние книги.
        
    
        Live-команда агента
        Кнопка «Команда агента» в режиме чтения показывает, как смена пресета приходит по IPC.
