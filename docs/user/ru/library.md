# Библиотека

Библиотека — главный экран окна. Здесь видны ваши книги, их группы и подробности
выбранной книги.

## Панель инструментов

| Элемент | Что делает |
|---|---|
| Кнопка боковой панели | Показывает или прячет боковую панель. |
| Поле поиска | Фильтрует книги по названию или автору. Enter открывает первое совпадение. |
| Группы | Группирует книги по полкам, авторам, формату, статусу или не группирует. |
| Порядок | Сортирует книги: недавно читали, название, автор, прогресс или дата добавления. |
| Добавить книги (`Ctrl+O`) | Открывает диалог выбора файлов. Файлы можно также перетащить в окно. |
| Мини-библиотека (`M`) | Переключает на маленькое окно. См. [мини-библиотеку](#мини-библиотека). |
| Настройки (`Ctrl+,`) | Открывает настройки. См. [настройку](configuration.md). |

## Боковая панель

- **Библиотека** показывает число книг в группах «Все книги», «Читаю»,
  «Не начата», «Прочитана» и «Брошена».
- **Полки** — ваши полки. Нажмите **+**, чтобы создать полку. Правый щелчок по
  полке открывает переименование и удаление. При удалении полки книги остаются в
  библиотеке. Перетащите корешок на полку, чтобы положить книгу на неё.
- **Авторы** показывает первых 10 авторов. Нажмите **Показать всех**, чтобы
  увидеть остальных.

## Книги на полках

Книги стоят на полках корешками. У каждого корешка свой цвет переплётного
полотна, золотое название и фамилия автора. Высота корешка зависит от объёма
книги. Книги расставлены по выбранной группировке.

Золотая ленточка на корешке отмечает книгу, которую вы читаете.

- Щёлкните корешок, чтобы выбрать книгу. Двойной щелчок или Enter открывает её.
- Стрелки перемещают выделение между корешками.
- F2 открывает редактирование выбранной книги.
- Delete удаляет выбранную книгу. Окно попросит подтверждение.

## Подробности книги

В правой панели показаны подробности выбранной книги:

- **Обложка.** У EPUB и FB2 своя обложка. Для PDF обложкой служит первая
  страница. Можно выбрать любое изображение.
- **Название, авторы и прогресс.** Полоска прогресса показывает процент
  прочитанного.
- **Кнопки.** **Продолжить** или **Читать** открывает книгу. **Изменить данные**
  меняет сведения о книге. **Ещё** (…) открывает меню книги.
- **Статус.** Не начата, читаю, прочитана или брошена.
- **Атмосфера.** Пресет или «По умолчанию». См. [атмосферу](atmosphere.md).
- **Полки.** Каждая полка показана плашкой. Нажмите × на плашке, чтобы убрать
  книгу с полки. Кнопка **На полку** открывает меню с флажками и пунктом
  **Новая полка**.
- **Сведения.** Формат, число страниц или глав, объём в словах, дата добавления,
  дата последнего открытия и путь к файлу.

## Меню книги

Щёлкните корешок правой кнопкой или нажмите **Ещё** (…) в панели подробностей,
чтобы открыть меню книги.

| Пункт | Что делает |
|---|---|
| Читать или Продолжить | Открывает книгу. |
| Изменить данные | Меняет название, авторов (через запятую) и обложку. |
| Полки | Добавляет книгу на полку или снимает её с полки. |
| Статус | Задаёт статус. |
| Атмосфера | Задаёт атмосферу для этой книги. |
| Сменить обложку… | Выбирает другое изображение обложки. |
| Читать с начала | Сбрасывает позицию чтения. Заметки остаются. |
| Скопировать путь к файлу | Копирует путь к файлу книги. |
| Удалить из библиотеки… | Убирает книгу из библиотеки. Файл остаётся на диске, если библиотека не хранила его копию. |

## Названия и авторы

Название PDF берётся из метаданных файла, если они выглядят настоящими. Иначе
оно берётся из имени файла. Библиотека убирает пометки сайтов-источников, например
«(z-library.sk, 1lib.sk)», и номер вида «(1)». Конец имени в скобках, например
«(Имя Автора)», становится автором. В именах файлов в стиле CamelCase появляются
пробелы.

Название и авторов можно поменять в любой момент: **Изменить данные**.

## Полки и статус

Полка — это метка. Книга может стоять на нескольких полках. Перемещение книги
между полками не меняет файл. Полки можно также менять из терминала командой
`vibe-reader shelf`.

Открытие книги ставит ей статус «Читаю». Статус «Прочитана» или «Брошена» можно
задать в панели подробностей или в меню книги. Группировка «Статус» раскладывает
библиотеку по статусам.

## Добавление многих книг

Когда вы добавляете несколько файлов, в углу окна появляется карточка хода
добавления. Файлы разбираются в фоне.

Большой PDF открывается несколько секунд при первом открытии. После этого
разобранная книга сохраняется в кэше и открывается сразу.

## Мини-библиотека

Нажмите `M` или кнопку мини-библиотеки на панели инструментов. Окно сжимается в
узкую полоску 760 на 340 пикселей. В ней одна полка с недавно открытыми книгами и
строка **Продолжить** для последней открытой книги.

Нажмите `M` ещё раз или ту же кнопку, чтобы вернуть полное окно. Открытие книги
из мини-библиотеки тоже возвращает полное окно.

Чтобы программа запускалась в мини-библиотеке, включите **Запускать
мини-библиотеку** в Настройках, в разделе «Библиотека».

Тайловые оконные менеджеры (niri, sway, Hyprland) могут не менять размер окна.
Раскладка всё равно переключится на компактную.

## Удаление книги

Нажмите Delete или выберите **Удалить из библиотеки…** в меню книги. Библиотека
забудет книгу вместе с заметками и историей чтения. Файл остаётся на диске.

Команда `vibe-reader remove` в терминале делает то же. Она спрашивает
подтверждение и работает только в терминале.
