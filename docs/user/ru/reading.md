# Чтение

## Читалка

Откройте книгу, и окно перейдёт в режим чтения. Окно и есть книга: сверху панели
инструментов нет. Название главы (для PDF — название книги) напечатано над
страницей как колонтитул. Номер страницы напечатан под ней как folio: «3 / 10»,
«121 / 530» или процент в режиме прокрутки. Щёлкните folio, чтобы ввести номер
страницы.

Элементы управления находятся на панели внизу окна. Она плавает над текстом:

| Элемент | Что делает |
|---|---|
| К библиотеке (`Esc`) | Возвращает в библиотеку. |
| Боковая панель (`T`) | Показывает или прячет боковую панель. |
| Перелистывание | Предыдущая страница, поле номера страницы, общее число страниц и следующая страница. Введите число и нажмите Enter, чтобы перейти на страницу. |
| Масштаб | Только для PDF. Показывает масштаб в процентах. См. [PDF](pdf.md). |
| Режим (`L`) | Выбирает раскладку. |
| Поиск (`Ctrl+F`) | Ищет по книге. Результаты показаны на вкладке «Поиск» боковой панели. |
| Переводчик (`Y`) | Открывает карточку переводчика. См. [переводчик](translator.md). |
| Для агента (✦) | Запоминает эту страницу, отправляет фрагмент или страницу, пишет сообщение агенту. См. [агентов](agents.md). |
| Атмосфера (значок с искрой) | Выбирает атмосферу этой книги. |
| Звук (`S`) | Включает или выключает фоновый звук. См. [звук](sound.md). |
| Светлое или тёмное (`D`) | Переключает оформление. |
| Полный экран (`F11`) | Переводит окно в полноэкранный режим. |
| Ещё (…) | Закладка на этой странице, переход к странице, поиск в книге, перевод этой страницы и настройки чтения. |

Панель скрывается примерно через 2,6 секунды без движения мыши, курсор скрывается
вместе с ней. Панель возвращается, когда мышь двигается. Чтобы панель не
скрывалась, выключите **Прятать управление при чтении** в Настройках, в разделе
«Чтение».

## Края страниц

Вдоль обеих сторон листа идут края страниц. Левый край растёт по мере чтения, а
правый уменьшается. Края страниц есть и у страниц и разворотов PDF.

## Перелистывание

В Настройки → Чтение → **Перелистывание** выбирается анимация:

- **Лист** (по умолчанию): в развороте правая страница переворачивается через
  корешок. Одиночная страница складывается к корешку.
- **Сдвиг**: колонки сдвигаются.
- **Без анимации**: страница меняется без движения.

«Меньше движения» отключает анимации.

## Заголовки глав

Когда вы доходите до новой главы, её название ненадолго, примерно на секунду,
появляется над столом.

## Раскладки

Для EPUB, FB2, Markdown и TXT есть три раскладки:

- **Разворот**: две страницы рядом, сшитые по центру. Нужно широкое окно.
- **Одна страница**: один лист во всю высоту окна.
- **Прокрутка**: непрерывный текст.

По умолчанию используется раскладка из Настроек, раздел «Чтение». Техническая
литература при выбранном развороте открывается одной страницей. Клавиша `L`
переключает раскладки по кругу.

У PDF свои раскладки. См. [PDF](pdf.md).

В технических книгах есть:

- подсвеченный код с кнопкой **Копировать**;
- формулы (TeX в Markdown, MathML в EPUB);
- таблицы, которые прокручиваются вбок, если они широкие;
- картинки, которые открываются в полный размер по щелчку.

## Боковая панель

`T` открывает боковую панель. Она выдвигается поверх стола, поэтому страница не
сдвигается. `Esc` закрывает панель. В ней пять вкладок:

- **Оглавление** показывает главы, вложенные главы выведены внутри своих. Для PDF
  здесь закладки самого PDF. См. [PDF](pdf.md).
- **Страницы** показывает миниатюры страниц. Щёлчок по миниатюре открывает эту
  страницу. Вкладка есть только для PDF.
- **Заметки** показывает все выделения, заметки и закладки книги. Щёлчок по
  пункту переводит к нему. Кнопка удаления или правый щелчок удаляют пункт.
  Так можно удалить и заметки агента.
- **Поиск** ищет по всему тексту. Щёлчок по результату переводит к нему. Найденное
  место несколько секунд подсвечено.
- **Агент** показывает то, что вы отправили агенту из окна, и ваши сообщения,
  сначала новые, вместе с ответами агента. Щёлчок по пункту переводит к его
  месту. Кнопка удаления убирает пункт. См. [агентов](agents.md).

## Заметки, выделения и закладки

Выделите текст, и появится панель: **Выделить**, **Заметка**, **Перевести**,
**Отправить выделенное**, **Копировать** и **Найти в книге**. Нажмите **Заметка**,
чтобы написать заметку. `Ctrl+Enter` сохраняет заметку.

`B` ставит закладку на текущую страницу. `N` открывает заметки.

- Ваши выделения подчёркнуты золотой линией.
- Заметки и выделения, сделанные ИИ-агентом, синие, с пунктирным подчёркиванием.
  На полях стоит отметка ✦. Щёлкните её, чтобы прочитать заметку.
- Щёлкните по выделенному тексту, чтобы открыть его заметку. В ней можно
  изменить свою заметку или удалить любое выделение и заметку, в том числе
  агентские.

Все заметки, выделения и закладки можно выгрузить из терминала командой
`vibe-reader export notes`.

## Типографика

Откройте Настройки (`Ctrl+,`) и перейдите в раздел «Чтение». Там можно поменять
раскладку книг, шрифт, размер, длину строки, интерлиньяж, выравнивание и переносы.
На странице настроек видно живое превью. Изменения применяются сразу и
сохраняются в `config.toml`. См. [настройку](configuration.md).

Встроенные шрифты (все с кириллицей): Literata, Spectral, Cormorant Garamond,
Playfair Display, Onest и JetBrains Mono. Можно выбрать системный шрифт или любое
установленное семейство шрифтов, записав его в `config.toml`.

## Атмосфера

Меню атмосферы в читалке задаёт пресет для открытой книги или «По умолчанию». Там
же включаются и выключаются частицы. Атмосфера рисуется на столе вокруг страницы
и никогда не ложится поверх текста. См. [атмосферу](atmosphere.md).
