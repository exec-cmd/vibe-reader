# Клавиатура

vibe-reader рассчитан на клавиатуру. Мышь и тачпад тоже работают.

## Везде

| Клавиша | Действие |
|---|---|
| `Ctrl+Shift+P` | Палитра команд: команды и книги |
| `Esc` | Закрыть всплывающее окно; в книге — вернуться в библиотеку |

## Библиотека

| Клавиша | Действие |
|---|---|
| `Ctrl+O` | Добавить книги |
| `Ctrl+,` | Настройки |
| `M` | Развернуть или свернуть мини-библиотеку |
| `←`, `→`, `↑`, `↓` | Перемещение между корешками |
| `Enter` | Открыть выбранную книгу |
| `F2` | Изменить выбранную книгу |
| `Delete` | Удалить выбранную книгу (сначала спросит) |

## Чтение

| Клавиша | Действие |
|---|---|
| `→`, `Space`, `Page Down` | Следующая страница |
| `←`, `Shift+Space`, `Page Up` | Предыдущая страница |
| `↑`, `↓` | Прокрутка |
| `]`, `[` | Следующая, предыдущая глава (в PDF: 10 страниц) |
| `Home`, `End` | Начало, конец главы |
| `G` | Перейти к странице |
| `T` | Боковая панель |
| `N` | Заметки |
| `Ctrl+F` | Поиск |
| `B` | Закладка на этой странице |
| `L` | Сменить раскладку |
| `D` | Светлое или тёмное оформление |
| `Ctrl+=`, `+` | Увеличить (PDF) |
| `Ctrl+-`, `-` | Уменьшить (PDF) |
| `0` | Сбросить масштаб (PDF) |
| `F11` | Полный экран |
| `Ctrl+Enter` в заметке | Сохранить заметку |

## Клавиши Vim

Включите **Клавиши Vim** в Настройках, в разделе «Клавиши», или задайте
`vim = true` в `config.toml`. Тогда добавятся:

| Клавиша | Действие |
|---|---|
| `l`, `h` | Следующая, предыдущая страница |
| `j`, `k` | Прокрутка вниз, вверх |
| `g`, `G` | Начало, конец главы |

При включённых клавишах Vim `l` листает страницу и не меняет раскладку. Раскладку
меняйте кнопкой на панели инструментов.

В Настройках, в разделе «Клавиши», есть и список всех сочетаний.
