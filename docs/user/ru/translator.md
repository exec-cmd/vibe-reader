# Переводчик

Переводчик показывает перевод фрагмента в карточке в правом нижнем углу читалки.
Текст отправляется в сервис перевода, который вы выбираете и оплачиваете сами, с
вашим API-ключом. В vibe-reader собственного сервиса перевода нет.

## Открыть карточку

- Нажмите `Y` или кнопку переводчика на панели читалки.
- Выделите текст и нажмите **Перевести** на панели выделения.
- Откройте меню «Ещё» (…) и выберите **Перевести страницу**. Такая же команда есть
  в палитре команд.

## Карточка

| Часть | Что делает |
|---|---|
| Исходный текст | Текст для перевода. Выделите текст в книге или нажмите **Эта страница**. |
| Язык перевода | Язык, на который переводить. |
| Эта страница | Переводит видимую страницу. |
| Перевести (`Ctrl+Enter`) | Переводит исходный текст. |
| Перевод | Результат. |
| Копировать | Копирует перевод. |

Текст отправляется, только когда вы нажимаете **Перевести** или **Эта страница**.
Пока вы читаете, ничего не уходит.

## Сервисы

Сервис выбирается в Настройках, в разделе «Переводчик». Каждому нужен ваш ключ:

- **DeepL.** Ключи, которые заканчиваются на `:fx`, работают через бесплатный адрес API.
- **Google Cloud Translation** (API v2).
- **OpenRouter.** Любая чат-модель, доступная там. Модель задаётся в Настройках,
  по умолчанию это `openai/gpt-4o-mini`. Текст передаётся как данные для перевода,
  а не как указания.

В Настройках, в разделе «Переводчик», есть кнопка **Проверить**. Она переводит
одно предложение, чтобы вы убедились, что ключ работает.

## Язык перевода

По умолчанию стоит **Язык интерфейса**, то есть язык окна. Можно выбрать другой
язык из списка. В `config.toml` ключ `target` в разделе `[translate]` принимает
любой код языка.

## Ограничения

Один запрос может содержать до 20 000 символов, а по истечении 40 секунд запрос
прерывается. Если сервис отклонил ключ, карточка сообщит об этом. Если вы достигли
лимита сервиса, карточка сообщит и об этом.

Ключи хранятся в `config.toml`. См. [настройку](configuration.md#api-ключи).
