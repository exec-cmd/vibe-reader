# Начало работы

## Установка

vibe-reader состоит из двух программ:

- `vibe-reader-gui`, окно читалки;
- `vibe-reader`, командная строка для вас и для ИИ-агентов.

Установите обе из исходников (требования в [сборке](../../dev/building.md)):

```bash
cargo install --path src/cli
cargo install --path src/gui
```

Готовые сборки для Linux (архив с CLI и AppImage) прикладываются к каждому
релизу на GitHub.

## Добавьте первую книгу

Запустите окно:

```bash
vibe-reader-gui
```

Затем добавьте книги одним из способов:

- нажмите **Добавить книги** на панели инструментов или `Ctrl+O`;
- перетащите файлы в окно.

Из терминала:

```bash
vibe-reader add ~/Books/crime-and-punishment.epub --shelf Classics
vibe-reader open
```

Библиотека хранит ссылку на файл. Чтобы сохранить копию в библиотеке, добавьте
`--copy` или включите **Хранить копии добавленных файлов** в Настройках, в разделе
«Библиотека». Поддерживаются форматы EPUB, FB2, PDF, Markdown, TXT и HTML.

## Чтение

Дважды щёлкните корешок или выберите его и нажмите Enter. Чтобы вернуться в
библиотеку, нажмите `Esc`. Тонкая полоска прогресса вверху показывает, сколько
вы прочитали. Окно запоминает, где вы остановились.

Переключайте раскладку кнопкой на панели или клавишей `L`. По умолчанию
используется раскладка из Настроек, раздел «Чтение» (для PDF — раздел «PDF»).

`Ctrl+Shift+P` открывает палитру команд. В ней есть команды и книги.

Подробнее: [библиотека](library.md), [чтение](reading.md), [PDF](pdf.md) и
[клавиши](keyboard.md).

## Быстрый просмотр файла

```bash
vibe-reader open notes.md --lite
```

Режим lite показывает один файл без библиотеки, атмосферы и анимаций. Книга
попадает в библиотеку, только когда вы нажмёте **Добавить в библиотеку**.
Markdown-файл в этом режиме перезагружается, когда вы сохраняете его в редакторе.
