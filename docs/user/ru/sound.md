# Звук

vibe-reader умеет играть фоновый звук во время чтения: дождь, грозу, огонь, ветер
или гул сети. По умолчанию звук выключен. Звуки создаются прямо в окне, поэтому
звуковые файлы не нужны.

## Включить

- Нажмите `S` в читалке или кнопку звука на панели читалки.
- Откройте палитру команд (`Ctrl+Shift+P`) и выберите **Звук**.
- Откройте Настройки → Звук и включите **Фоновый звук**.

## Звуки

| Тип | Что слышно |
|---|---|
| Дождь | Ровный дождь. |
| Гроза | Дождь, низкий рокот и гром после молнии. |
| Огонь | Потрескивание. |
| Ветер | Порывы. |
| Гул | Гул сети и вентилятор. |

Каждая атмосфера выбирает свой звук:

| Пресет | Звук |
|---|---|
| Study | Огонь |
| Terminal | Гул |
| Noir | Дождь |
| Soft | Ветер |
| Rain | Дождь |
| Storm | Гроза |
| Mountain | Ветер |

## Громкость

В Настройках, в разделе «Звук», есть ползунок громкости от 0 до 100 %. Каждая
атмосфера задаёт свой уровень, и он считается относительно ползунка. Поэтому при
том же ползунке звук тихой атмосферы остаётся тише.

## Как это работает

Звук плавно нарастает и затихает. Пока окно скрыто, он становится тихим, а при
выходе из читалки останавливается.

Чтобы послушать тип звука до включения, откройте Настройки → Звук и нажмите
**Послушать** рядом с ним. Образец играет 6 секунд.

## Свои атмосферы

Профиль может задать свой звук в разделе `[sound]`. См.
[атмосферу](atmosphere.md#звук).
