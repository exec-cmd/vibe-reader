# Атмосфера

У каждой книги может быть свой облик: палитра, пара шрифтов, фон, тихие частицы,
стиль заголовков глав, рисунок в начале каждой главы и световые эффекты. Глава или
отдельная сцена может иметь собственный облик поверх облика книги.

Атмосфера рисуется на столе вокруг страницы и никогда не ложится поверх текста.
В читалке меню атмосферы (значок с искрой на панели внизу окна) выбирает пресет
для открытой книги или «По умолчанию» и включает или выключает частицы. В
библиотеке тот же параметр есть в карточке каталога и в меню книги.

## Пресеты

| Пресет | Режимы | Настроение |
|---|---|---|
| `study` | светлый, тёмный | Тёплая настольная лампа, книжные полки, медленная пыль. Свет лампы — растровое пятно из точек, курсор — вторая лампа. По умолчанию. |
| `terminal` | светлый, тёмный | Моноширинный шрифт, а весь стол становится полем ASCII-волн, которые расходятся под курсором. Для кода и технических книг. |
| `noir` | светлый, тёмный | Свет через жалюзи штриховкой, зерно, высокий контраст; курсор отбрасывает тень. |
| `soft` | светлый, тёмный | Пастельный градиент, медленное боке и кольца жемчужин. |
| `rain` | только тёмный | Туман и дождь на стекле; курсор протирает запотевшее стекло, и оно снова запотевает. |
| `storm` | только тёмный | Тяжёлые тучи, ливень с полосами дождя под ветром, редкие слабые вспышки молний. |
| `mountain` | светлый, тёмный | Нарисованный горный пейзаж: снежные вершины под луной, мерцающие звёзды, хребет с соснами, туман и снегопад; курсор проявляет тусклые звёзды. |

Поле на столе каждого пресета движется несколько секунд после движения указателя
и затем замирает, так что спокойное чтение не тратит процессор. Щелчок рядом со
страницей пускает по нему кольцо. Его усиливает или ослабляет сила эффектов в
настройках; в облегчённом режиме его нет, а при уменьшенном движении оно стоит.

Пресеты, которые есть только в одном режиме (rain, storm), остаются тёмными, даже
когда остальная программа светлая.

У каждого пресета есть свой звук. См. [Звук](#звук).

```bash
vibe-reader preset list
vibe-reader atmosphere set --book 3 --preset rain               # вся книга
vibe-reader atmosphere set --book 3 --chapter 7 --preset storm  # одна глава
vibe-reader atmosphere set --book 3 --range ch:9:1200..ch:9:5400 --profile '{"particles": {"kind": "snow"}}'
vibe-reader atmosphere get --book 3
vibe-reader atmosphere clear --book 3 --chapter 7
```

Открытое окно читалки меняется сразу. `vibe-reader undo` отменяет последнее
изменение. Для книг без собственного облика используется `preset` из
`config.toml`. Его можно выбрать и в Настройках, в разделе «Атмосфера».

## Как написать профиль

Профиль перечисляет только то, что он меняет. Поле `base` берёт за основу пресет:

```toml
base = "noir"

[particles]
kind = "rain"
density = 0.4

[palette.dark]
accent = "#d4a24c"
```

Полный список полей и их диапазоны описан в
[схеме атмосферы](../../dev/atmosphere-schema.md). Команда
`vibe-reader preset show study` выводит полный пример. Профили используют только
встроенные шрифты и не могут содержать CSS. Профиль, текст которого плохо читается
(контраст ниже 4,5:1), отклоняется с указанием причины.

## Свои пресеты

Пресет — это профиль с разделом `[preset]`:

```toml
[preset]
name = "Autumn"
description = "Amber light and falling dust."
modes = ["light", "dark"]

[palette.light]
paper = "#f6efe2"
ink = "#2e261f"
# ...
```

Установите его командой `vibe-reader preset install autumn.toml`. Можно добавить
`--css autumn.css` для оформления, которое схема не описывает. Файлы из папки
`~/.config/vibe-reader/presets/` подхватываются сразу. Пресет с именем встроенного
заменяет его.

## Иллюстрации

```bash
vibe-reader art add 3 ./chapter7.png --locator ch:7:0 --as chapter
vibe-reader art add 3 ./map.svg --locator ch:2:4800 --as page
vibe-reader art add 3 ./cover.jpg --as cover
```

| Размещение | Где появляется |
|---|---|
| `chapter` | В начале главы вместо рисунка из пресета. |
| `margin` | Рядом с абзацем в локаторе. |
| `page` | Вся страница вставляется в локатор. |
| `cover` | Обложка книги в библиотеке. |

Принимаются PNG, JPEG, WebP, GIF и SVG размером до 10 МБ. SVG со скриптами или
внешними ссылками отклоняется. vibe-reader сам изображения не создаёт: агент может
передать готовый файл или ссылку.

## Эффекты

В настройках, в разделе «Атмосфера», пункт **Эффекты** задаёт силу световых
эффектов от 0 до 200 %. При значении «Выкл.» остаются только цвета. Сила влияет на
фон, свечение, виньетку, зерно, число частиц и вспышки молнии. В `config.toml` то же
самое задаёт `effects` в разделе `[reader]`: от 0 до 2, где 1 — как задумано.

Частицы взаимодействуют с книгой:

- Снег садится на верхний край страницы и тает примерно за десять секунд.
- Дождь разбрызгивается о верхний край страницы.
- Перелистывание страницы создаёт порыв, который сдувает пыль, снег и боке.
  Дождь немного гнётся.

Пресет Storm вспыхивает молнией по всей комнате, включая страницу. Если звук
включён, гром раздаётся через небольшую паузу.

## Звук

Профиль может задать атмосфере фоновый звук в разделе `[sound]`:

```toml
[sound]
kind = "rain"
volume = 0.4
```

`kind` — это `none`, `rain`, `storm`, `fire`, `wind` или `hum`. `volume` меняется
от 0 до 1 и считается относительно громкости, заданной в Настройках, в разделе
«Звук». Неизвестный тип или громкость вне диапазона 0–1 не проходят проверку. До
версии 0.2.0 раздел `sound` был зарезервирован и игнорировался.

У встроенных пресетов есть звуки: у study — огонь, у terminal — гул, у noir и rain
— дождь, у soft и mountain — ветер, у storm — гроза. Как включить звук, описано в
[звуке](sound.md).

## Движение

Частицы идут не быстрее 30 кадров в секунду на одном холсте и останавливаются,
когда окно скрыто. Молния вспыхивает не чаще раза в 6 секунд. В режиме lite
атмосферы и анимаций нет. Частицы и переходы выключаются также переключателем
**Меньше движения** в настройках и тогда, когда система просит уменьшить движение.

## Изменение всего оформления

Атмосфера относится к читалке. Чтобы поменять всё остальное (библиотеку, панели,
отступы), положите CSS в `~/.config/vibe-reader/ui/user.css`. Окно применит его
на ходу. См. [интерфейс](../../dev/ui.md).
