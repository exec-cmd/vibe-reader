# Справочник командной строки

`vibe-reader` работает с той же библиотекой, что и окно читалки. У каждой команды
есть `--help` со всеми флагами. Эта страница даёт общий обзор.

## Вывод

- В терминале команды печатают текст в формате Markdown. В остальных случаях
  (каналы, скрипты, агенты) они печатают JSON. Флаги `--json` и `--md` задают формат
  явно.
- Ошибки в текстовом режиме идут в stderr. В режиме JSON они выводятся в stdout в виде
  `{"error": "..."}`. Код выхода равен 1.
- Текст из книг помечается как недоверенный: `"untrusted": true` в JSON и
  `<book-content untrusted="true">` в тексте. Почему так, см. в [агентах](agents.md).

## Выбор книги

Команды, которые принимают `<book>`, понимают id из `vibe-reader list`, путь к файлу
или уникальную часть названия: `vibe-reader show наказание`.

## Места в книге

Места задаются локаторами: `ch:3` — начало главы 3, `ch:3:120` — символ 120 этой
главы, а `ch:3:120..ch:3:480` — отрезок. Для PDF `ch:N` означает страницу N.
`vibe-reader toc <book>` выводит локаторы глав.

## Команды

### Библиотека

| Команда | Что делает |
|---|---|
| `add <file\|url> [--copy] [--shelf NAME]` | Добавляет книгу. Библиотека ссылается на файл; `--copy` сохраняет копию. Ссылки скачиваются в библиотеку. |
| `remove <book>` | Удаляет книгу вместе с заметками и историей. Спрашивает подтверждение; работает только в терминале. |
| `list [--shelf NAME] [--group shelf\|author]` | Список книг, сначала недавно открытые. |
| `show <book>` | Сведения об одной книге. |
| `open [file\|book] [--lite]` | Открывает окно читалки, файл или книгу библиотеки. `--lite` — быстрый просмотр без библиотеки и атмосферы. Запущенное окно берёт файл на себя. |
| `shelf create\|rename\|delete\|list\|add\|remove` | Виртуальные полки. Книга может стоять на нескольких полках. |
| `status set <book> reading\|finished\|dropped` | Статус книги. Открытие книги ставит статус «читаю». |
| `art add <book> <image> --locator L [--as page\|chapter\|margin\|cover]` | Прикрепляет иллюстрацию (PNG, JPEG, WebP, GIF, SVG до 10 МБ). |
| `art list <book>`, `art remove <id>` | Выводит или открепляет иллюстрации. |

### Чтение

| Команда | Что делает |
|---|---|
| `toc <book>` | Оглавление с локаторами. |
| `read [book] [--chapter N \| --locator L \| --range A..B \| --continue] [--max-tokens N]` | Текст книги кусками. В результате указан следующий локатор `next`; `--continue` продолжает с последнего прочитанного куска. |
| `search <book> <query> [--regex]` | Поиск с локатором и фрагментом для каждого совпадения. |
| `context [book]` | Текущее место: глава, позиция, недавний текст, ближайшие заметки. |
| `progress <book> [--set L]` | Позиция и прогресс; `--set` переводит позицию. |
| `stats [book]` | Главы, слова и время чтения. |
| `recap <book>` | Что читали в последней сессии, с вашими заметками. |

Команды `read`, `search`, `context` и `recap` останавливаются на вашей позиции в
книге, поэтому агент не может раскрыть то, что вы ещё не читали. Ключ
`--allow-spoilers` снимает ограничение; у прочитанных книг ограничения нет.

### Заметки и память

| Команда | Что делает |
|---|---|
| `note add <book> "текст" --locator L` (или `--range A..B`) | Добавляет заметку. |
| `note list <book>`, `note edit <id> "текст"`, `note delete <id>` | Управление заметками. |
| `bookmark add <book> --locator L [label]`, `bookmark list <book>` | Закладки. |
| `highlight add <book> --range A..B [--note "текст"]`, `highlight list <book>` | Выделения. |
| `export notes [book] [-o notes.md\|notes.json]` | Экспорт заметок, выделений и закладок. |
| `memory set\|get\|list --book <book>` | Факты, которые агент хранит о книге между сессиями. |
| `undo` | Отменяет последнюю заметку, запись в памяти, иллюстрацию или изменение атмосферы текущего автора. |

### Атмосфера и живое окно

| Команда | Что делает |
|---|---|
| `atmosphere set --book B [--chapter N \| --range A..B] (--preset NAME \| --file F \| --profile TEXT)` | Задаёт облик книги, главы или сцены. |
| `atmosphere get --book B [--locator L]` | Сохранённые профили и облик, который действует. |
| `atmosphere clear --book B [--chapter N \| --range A..B]` | Убирает профиль. |
| `preset list\|show NAME\|validate FILE\|install FILE [--css F]` | Пресеты. |
| `live position\|selection` | Что показывает запущенное окно. |
| `live goto L`, `live highlight A..B` | Поворачивает окно; показывает фрагмент. |
| `gui status` | Запущено ли окно. |

См. [атмосферу](atmosphere.md).

### Статистика чтения

| Команда | Что делает |
|---|---|
| `sessions [--period day\|week\|month\|year\|all] [--book B]` | Сессии чтения. |
| `stats --reader [--period P]` | Скорость, время суток, объём. |

Обе команды показывают только то, что вы разрешили в `[agent.consent]`
([настройка](configuration.md)).

### Служебные команды

| Команда | Что делает |
|---|---|
| `skills install [--dir DIR] [--force]`, `skills list` | Установка Agent Skills (по умолчанию `~/.claude/skills`). |
| `config`, `config path`, `config edit` | Показ и изменение настроек. |
| `doctor` | Проверка установки и библиотеки. |

## Авторы

Заметки, выделения, закладки, память, иллюстрации и атмосфера записывают, кто их
создал. В терминале автор — `user`, иначе — `agent`. Явно задать автора можно
флагом `--author NAME` или переменной `VIBE_READER_AUTHOR=NAME`. Агент может менять
и удалять только свои записи.
